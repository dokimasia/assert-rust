# RFCs

An RFC records the argument behind a decision, so someone reading the
code later can tell what was weighed rather than guessing.

| # | Title | Status |
|---|---|---|
| [0001](0001-the-rust-implementation.md) | The Rust assertion library | Accepted |

Statuses are Draft, Review, Accepted, Rejected, Withdrawn and
Superseded. A rejected RFC stays on disk: it is the record of why not.
